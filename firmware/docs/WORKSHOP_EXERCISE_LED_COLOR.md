# תרגיל סדנה: בחירת צבע קבוע ל-LED במקום קשת בענן

## המטרה

כרגע, ה-LED הצבעוני (RGB) שדולק בזמן נגינה (או תמיד, אם מצב ה-LED ב-SETTINGS מוגדר ל-ALWAYS) עושה **קשת בענן** — משנה צבע ברציפות. במשימה הזו נחליף את זה **לצבע קבוע אחד לבחירתכם**.

לא נוגעים במתי ה-LED דולק (זה כבר מוגדר ב-SETTINGS ← LED, AUTO/ALWAYS), רק **באיזה צבע** הוא דולק.

---

## רקע: איפה זה מוגדר

קובץ אחד בלבד מעורב: **`src/StatusLed.cpp`**, בפונקציה `update()`:

```cpp
void StatusLed::update()
{
    if (!_pixel)
    {
        return;
    }

    if (_mode == LedMode::Always || audioController.isPlaying())
    {
        _hue += HueStepPerTick;
        _pixel->setPixelColor(
            0,
            _pixel->gamma32(_pixel->ColorHSV(_hue)));
    }
    else
    {
        _pixel->setPixelColor(0, 0);
    }
    _pixel->show();
}
```

השורה `_hue += HueStepPerTick;` מקדמת את הצבע קדימה בכל "טיק" (כל קריאה ל-`update()`, שקורה כל הזמן בלולאה הראשית) — זה מה שיוצר את אפקט קשת-בענן. השורה `_pixel->ColorHSV(_hue)` הופכת את הערך המתקדם הזה לצבע בפועל.

---

## ⚠️ שימו לב: זה **לא** אותו פורמט צבע כמו במסך!

בתרגילים הקודמים (למשל צבעי המחבטים בהוקי אוויר) השתמשנו בפורמט **RGB565** — מספר אחד ארוז (`0x07FF` וכו') עבור המסך.

ה-LED כאן הוא **NeoPixel (WS2812)**, שמשתמש בפורמט אחר לגמרי: **שלושה מספרים נפרדים**, אחד לכל ערוץ (אדום, ירוק, כחול), כל אחד בין **0 ל-255**. אין קשר בין שני הפורמטים — זו הזדמנות טובה להבין שלא כל רכיב חומרה "מדבר" באותה שפת צבעים.

---

## שלב 1 — בחרו צבע קבוע

פתחו את `src/StatusLed.cpp`. מצאו את השורות:

```cpp
_pixel->setPixelColor(
    0,
    _pixel->gamma32(_pixel->ColorHSV(_hue)));
```

והחליפו אותן ב:

```cpp
_pixel->setPixelColor(
    0,
    _pixel->gamma32(_pixel->Color(255, 0, 0)));
```

(הדוגמה למעלה היא אדום מלא. שנו את שלושת המספרים לצבע שאתם רוצים — ראו טבלה למטה.)

**את השורה `_hue += HueStepPerTick;` שמעליה אין צורך למחוק** — היא פשוט תפסיק להיות בשימוש בפועל, וזה בסדר גמור.

## שלב 2 — קומפילציה, העלאה, ובדיקה

1. שמרו את הקובץ.
2. הריצו `pio run -e esp32s3` ובדקו שאין שגיאות קומפילציה.
3. אם הכול תקין: `pio run -e esp32s3 -t upload` כדי להעלות לבקר.
4. **בדיקה בפועל**: לכו ל-SETTINGS ← LED, הגדירו ALWAYS (כדי לראות את ה-LED דולק גם בלי נגינה), ותראו את הצבע הקבוע שבחרתם במקום קשת הבענן.

---

## אתגר בונוס (לא חובה)

1. **מהירות קשת בענן**: אם דווקא אהבתם את קשת הבענן ורק רוצים לשנות את המהירות שלה — במקום להחליף ל-`Color()` קבוע, שנו את הערך של `HueStepPerTick` בראש הקובץ (מספר גדול יותר = קשת מהירה יותר, מספר קטן יותר = איטית יותר).
2. **אתגר מתקדם**: לנסות לגרום לצבע ה-LED להשתנות לפי **עוצמת הווליום** הנוכחית (רמז: יש ל-`AudioController` דרך לבדוק את הווליום הנוכחי — חפשו איך `JukeboxUI` משתמש בזה כדי להציג את אחוז הווליום על המסך, ותצטרכו למצוא דרך דומה לגשת אליו מתוך `StatusLed`).
