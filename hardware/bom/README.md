# Bill of Materials

- [`COMPONENTS.md`](COMPONENTS.md) — plain-text/Markdown version of the BOM, readable directly on GitHub, no spreadsheet app needed.
- [`ESP32_Jukebox_BOM_English_Open_Source.xlsx`](ESP32_Jukebox_BOM_English_Open_Source.xlsx) — the English spreadsheet `COMPONENTS.md` was generated from.
- [`ESP32_Jukebox_BOM_AliExpress_Prices_3105.xlsx`](ESP32_Jukebox_BOM_AliExpress_Prices_3105.xlsx) — original Hebrew working spreadsheet (workshop-quantity multiplier, price-sourcing notes).

Full component list for building a Juckbox, with quantities, specs, and per-unit prices. See the **Notes** sheet inside either spreadsheet for how to use it (link types, adjusting workshop quantity, price sourcing).

Most links currently point to an AliExpress search for the part (so you can pick a seller by stock, shipping, and rating) rather than one specific listing — the exception is the ESP32 display board, which links directly to the supplied listing.

## Affiliate Disclosure

Some links in this BOM may be AliExpress affiliate links, marked **Affiliate** in the sheet once added. If you purchase through a marked link, the project maintainer may receive a small commission at no additional cost to you — this never affects which component is recommended, and using the link is entirely optional. Every row also lists the part's name and search specification, so you can always look it up independently instead.
