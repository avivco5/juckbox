הוספת המימוש

src/JukeboxUI.cpp

פתחו את src/JukeboxUI.cpp. מצאו את הפונקציה בערך בשורה 507:

הפונקציה הקיימת מעבירה לשיר הבא 
void JukeboxUI::nextSong()
{
    if (songCount() > 0)
    {
        const int current = max(0, _songIndex);
        selectSong((current + 1) % songCount());
    }
}

מיד אחריה הוסיפו פונקציה חדשה, דומה כמעט לגמרי. במקום + 1 נשתמש ב- + songCount() - 1.

הפונקציה החדשה השורה הירוקה מבצעת מעבר אחורה 
void JukeboxUI::previousSong()
{
    if (songCount() > 0)
    {
        const int current = max(0, _songIndex);
        selectSong((current + songCount() - 1) % songCount());
    }
}
💡

למה לא להשתמש פשוט ב-1-?

ב-C++ אופרטור ה-% לא מתנהג יפה עם מספרים שליליים. הביטוי (current - 1) % songCount() יכול להיות שלילי כאשר current == 0. החישוב current + songCount() - 1 שומר על תוצאה חיובית ומאפשר "גלגול" מהשיר הראשון לשיר האחרון.

הערה חשובה

התרגיל משנה רק את כפתור ה-NEXT המחובר ל-GPIO45. כפתור PLAY/PAUSE המחובר ל-GPIO46 ממשיך לעבוד כרגיל.

כאשר משחקים בפינבול או בהוקי אוויר מלשונית GAMES, שני הכפתורים משמשים כפקדי משחק ולא כ-NEXT או PLAY/PAUSE. השינוי משפיע רק כשלא משחקים במשחק. ניתן לראות זאת בתנאי if (jukeboxUI.isPlayingGame()) בקובץ main.cpp.
