🌈 תרגיל סדנה - LED ו-NeoPixel

בחירת צבע קבוע ל-LED במקום קשת בענן

נחליף את אפקט קשת הבענן של ה-LED הצבעוני בצבע קבוע אחד לבחירתכם. לא משנים מתי ה-LED דולק, אלא רק באיזה צבע הוא מאיר.

2 שלבים קובץ אחד NeoPixel WS2812 ללא שינוי בחומרה
🎯

המטרה

כרגע, ה-LED הצבעוני דולק בזמן נגינה, או תמיד כאשר מצב ה-LED ב-SETTINGS מוגדר ל-ALWAYS, ומשנה צבע ברציפות כמו קשת בענן. במשימה הזו נחליף אותו בצבע קבוע אחד לבחירתכם.

1. בוחרים צבע 2. מחליפים את הקוד 3. מקמפלים ומעלים 4. בודקים ב-ALWAYS
📁

זה לא אותו פורמט צבע כמו במסך

בתרגילים של המסך השתמשנו ב-RGB565, למשל 0x07FF. ה-LED כאן הוא NeoPixel מסוג WS2812 ומשתמש בשלושה מספרים נפרדים: אדום, ירוק וכחול. כל מספר הוא בין 0 ל-255.

בחרו צבע קבוע והחליפו את הקוד

src/StatusLed.cpp

פתחו את src/StatusLed.cpp ומצאו בתוך הפונקציה update() את קטע הקוד הבא:

לפני השינוי הצבע מחושב לפי _hue המשתנה 
_pixel->setPixelColor(
    0,
    _pixel->gamma32(_pixel->ColorHSV(_hue)));

החליפו את השורות בקוד הבא. הדוגמה משתמשת באדום מלא:

אחרי השינוי המספרים בסוגריים קובעים את הצבע 
_pixel->setPixelColor(
    0,
    _pixel->gamma32(_pixel->Color(255, 0, 0)));
💡

מה מייצגים שלושת המספרים?

הסדר הוא אדום, ירוק, כחול. לדוגמה, 255, 0, 0 הוא אדום מלא, ו-0, 0, 255 הוא כחול מלא.

📝

אין צורך למחוק את שורת ה-hue

אפשר להשאיר את _hue += HueStepPerTick; כפי שהיא. לאחר המעבר ל-Color() קבוע, הערך פשוט לא ישפיע על הצבע שמוצג.

קומפילציה, העלאה ובדיקה

PlatformIO / ESP32-S3

בצעו את הפעולות לפי הסדר:

✓
שמרו את הקובץ src/StatusLed.cpp.
✓
הריצו קומפילציה ובדקו שאין שגיאות: pio run -e esp32s3
✓
אם הכול תקין, העלו את הקוד לבקר: pio run -e esp32s3 -t upload
✓
היכנסו ל-SETTINGS, פתחו LED ובחרו ALWAYS. כך אפשר לראות את ה-LED גם בלי להפעיל שיר.
✓
ודאו שה-LED מציג את הצבע הקבוע שבחרתם ולא קשת בענן.
⚠️

AUTO ו-ALWAYS עדיין פועלים כרגיל

התרגיל משנה רק את הצבע. במצב AUTO ה-LED יידלק בזמן נגינה, ובמצב ALWAYS הוא יישאר דולק כל הזמן.

🚀

אתגר בונוס - לא חובה

  1. שינוי מהירות הקשת: אם אתם מעדיפים להשאיר את אפקט הקשת, שנו את הערך של HueStepPerTick בראש הקובץ. ערך גדול יותר ייצור קשת מהירה יותר, וערך קטן יותר ייצור קשת איטית יותר.
  2. אתגר מתקדם: נסו לשנות את צבע ה-LED לפי עוצמת הווליום. חפשו כיצד JukeboxUI מקבל את הווליום הנוכחי מ-AudioController ומציג אותו באחוזים.
