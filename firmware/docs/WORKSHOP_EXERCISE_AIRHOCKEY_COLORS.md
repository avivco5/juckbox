# תרגיל סדנה: שינוי צבעי המחבטים במשחק הוקי אוויר

## המטרה

לשנות את הצבעים של שני המחבטים (הלוחות) במשחק **הוקי אוויר** — המחבט של השחקן (שמאל) והמחבט של המחשב (ימין) — לצבעים לבחירתכם.

לא נוגעים בפיזיקה או בניקוד, רק בצבע.

---

## רקע: איפה הצבעים מוגדרים

קובץ אחד בלבד מעורב: **`src/AirHockeyGame.cpp`**.

בראש הקובץ (בערך שורות 31–39) מוגדרת רשימת כל הצבעים במשחק:

```cpp
constexpr uint16_t ColorBg = 0x0844;
constexpr uint16_t ColorWall = 0x39C7;
constexpr uint16_t ColorPuck = 0xFFE0;
constexpr uint16_t ColorPlayerPaddle = 0x07FF;
constexpr uint16_t ColorCpuPaddle = 0xF800;
constexpr uint16_t ColorText = 0xF7BE;
constexpr uint16_t ColorMuted = 0x8410;
constexpr uint16_t ColorWin = 0x07E0;
constexpr uint16_t ColorLose = 0xF800;
```

השורות שמעניינות אותנו:

```cpp
constexpr uint16_t ColorPlayerPaddle = 0x07FF;  // המחבט של השחקן (טורקיז/ציאן)
constexpr uint16_t ColorCpuPaddle = 0xF800;     // המחבט של המחשב (אדום)
```

השמות `ColorPlayerPaddle` ו-`ColorCpuPaddle` משמשים בהמשך הקובץ (בפונקציה `draw()`, בערך שורות 213–214) כדי לצייר את שני המחבטים בפועל — **אין צורך לגעת שם**, מספיק לשנות את הערך כאן, למעלה, ושני הציורים יתעדכנו אוטומטית.

---

## שלב 1 — שנו את צבע המחבט של השחקן

פתחו את `src/AirHockeyGame.cpp`. מצאו את השורה:

```cpp
constexpr uint16_t ColorPlayerPaddle = 0x07FF;
```

והחליפו את `0x07FF` בערך צבע אחר מהטבלה למטה (או בערך משלכם — ראו הסבר בסוף).

## שלב 2 — שנו את צבע המחבט של המחשב

באותו קובץ, מצאו את השורה:

```cpp
constexpr uint16_t ColorCpuPaddle = 0xF800;
```

והחליפו את `0xF800` בערך אחר מהטבלה.

**טיפ:** כדאי לבחור שני צבעים **שונים בבירור** אחד מהשני (ומרקע המשחק, שהוא כחול-כהה) — אחרת יהיה קשה להבחין מי המחבט שלכם ומי של המחשב תוך כדי משחק.

## טבלת צבעים מוכנה להעתקה

כל הערכים האלה כבר בשימוש במקום אחר בפרויקט ובדוקים שעובדים על המסך:

| צבע | קוד להעתקה |
|---|---|
| אדום | `0xF800` |
| ירוק | `0x07E0` |
| כחול | `0x001F` |
| צהוב | `0xFFE0` |
| ורוד | `0xF81F` |
| כתום | `0xFD20` |
| טורקיז (ציאן) | `0x07FF` |
| לבן | `0xFFFF` |

## למי שרוצה להבין איך זה עובד (לא חובה)

הצבעים כתובים בפורמט שנקרא **RGB565** — מספר בן 16 סיביות (bit) שמייצג צבע ב-3 ערוצים: אדום (Red), ירוק (Green), כחול (Blue). השם "565" מגיע מכך שמוקצים 5 סיביות לאדום, 6 לירוק, ו-5 לכחול (יותר לירוק כי העין האנושית רגישה אליו יותר).

לדוגמה `0x07FF` (הצבע המקורי של מחבט השחקן): ב-בינארי זה `00000` `111111` `11111` — כלומר אדום=0 (כלום), ירוק=מלא, כחול=מלא → טורקיז.

**רוצים צבע מדויק משלכם ולא מהטבלה?** אפשר לחפש ברשת "RGB565 color picker" — כלים כאלה נותנים לכם לבחור צבע על גלגל צבעים ומחזירים את הקוד המתאים ב-hex, בדיוק בפורמט שהקוד כאן מצפה לו (`0xXXXX`).

## שלב 3 — קומפילציה, העלאה, ובדיקה

1. שמרו את הקובץ.
2. הריצו `pio run -e esp32s3` (לבדיקה כללית) או `pio run -e airhockey` (אם רוצים לבדוק רק את משחק הוקי האוויר העצמאי) — ובדקו שאין שגיאות קומפילציה.
3. אם הכול תקין: `pio run -e esp32s3 -t upload` (או `-e airhockey -t upload` למשחק העצמאי) כדי להעלות לבקר.
4. **בדיקה בפועל**: היכנסו ללשונית GAMES ← AIR HOCKEY, ותראו את שני המחבטים בצבעים החדשים שבחרתם.

## אתגר בונוס (לא חובה)

1. נסו לשנות גם את **`ColorPuck`** (צבע הדיסקית) או **`ColorBg`** (צבע הרקע) באותו האופן.
2. אתגר מתקדם יותר: מי שרוצה, יכול לנסות לגרום לצבע מחבט השחקן **להשתנות** כל פעם שהוא מקבל נקודה (רמז: תצטרכו למצוא איפה `_playerScore` מתעדכן בקובץ, ולהוסיף שם קוד ששולף צבע אחר ממערך צבעים בכל פעם).
